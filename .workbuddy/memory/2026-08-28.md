## 电脑端(网页版) Review 与修复
收到"review一下，看看有没有错误"指令，对 web/ 三件套做正式 review，发现并修复 2 个关键 bug：

1. **engine.js 加载方式错误（阻断级）**：磁盘上的 engine.js 被改写成 `fetch('runner.py')` 版，但 `web/` 目录里没有 runner.py → `loadEngine` 必然 404 → 整个应用起不来；且 `file://` 双击时 fetch 会被浏览器 CORS 拦截。
   - 修复：让 `gen_data.py` 重新生成 engine.js 为**内联版**（`window.ENGINE_PY`=runner.py 全文 + `window.REPL_HELPER_PY`），`app.js boot()` 改为优先 `pyodide.runPython(window.ENGINE_PY)`，不再依赖外部文件。现在 http 与 file:// 双击均可运行。
2. **REPL 助手拼写 bug（阻断级）**：`gen_data.py` 的 repl_helper 第 54 行写 `_repl_ns`（小写），定义却是 `_REPL_NS`（大写）→ REPL 一调用即 `NameError`。已改为 `_REPL_NS`。

验证：`node --check` 三个 JS 全过；`web/_verify_web_engine.py` 端到端跑通（REPL 有状态 / run_code_json / check_exercise_json / 死循环看门狗，全部 OK）。
