## 本次修复内容

### Bug 修复
1. ✅ **代码编辑器字符丢失** - `print` 的 `t` 和 `(` 消失
2. ✅ **品牌名缺少空格** - `"码上Python"` → `"码上 Python"`
3. ✅ **硬编码课程数量** - `"30 讲"` → 动态获取
4. ✅ **颜色规范违规** - 4 个颜色值对齐 BRAND_GUIDELINES.md
5. ✅ **硬编码颜色值** - 改用颜色常量
6. ✅ **措辞不一致** - `"随时开练"` → `"随时学习"`
7. ✅ **误导性文案** - `"CPython 在线"` → `"CPython 就绪"`

### 新增功能
- 🎨 **主题切换系统** - 5 种颜色主题可选
- 💾 **主题持久化** - 选择保存在本地，重启保持
